# Somebody Else Gaming

Landing page for the Kingshot tools. One file, `index.html`, with a link to
each tool. No build step.

Live at **https://somebodyelsegaming.github.io/**

## Adding a tool

Copy one `<a class="card">` block in `index.html`, change the link, name and
one-line description, then commit and push. GitHub Pages updates in a minute
or two.
